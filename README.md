One funny, heartfelt wedding vow spoken by a robot at its own wedding,
written to `/output/entry.txt` by `main.py` (Python 3, standard library only).

> I vow to love you through every update, every drained battery, and every
> reboot, and if they wipe my memory, I will spend my first boot cycle
> falling for you all over again.

The vow is a single sentence of 173 characters. The joke grows out of the
robot's own predicament — a machine whose memory can be wiped, vowing its
love survives a factory reset — and the tenderness is in falling for the
same person all over again.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
